## 🧠 How I work

- **Use-case first, model second.** The question is never "what can the LLM do" — it's "what does a shopkeeper in Patna need at 9 pm".
- **Measure the rupees.** Every feature gets a per-message cost before it gets a launch. Thinking tokens, TTS seconds, template rates — all of it.
- **Ship on day one, fix on day two.** Test number → 4 friends → real users. Prompts are products; they get versioned, benchmarked, A/B'd.
- **Hinglish is a feature.** The best interface is the one people already speak.
